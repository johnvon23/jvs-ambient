Audio served by the site (committed). Masters live in assets/sound/,
which is gitignored.

Files here are the original masters copied as-is, byte for byte. Never
re-encode or down-bitrate them (John's rule: a transcode degrades the
quality). To add a track: copy it from assets/sound/ under a lowercase,
dash-separated name and point the page's <audio> src at it.
